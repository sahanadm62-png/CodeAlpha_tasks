# CodeAlpha Restaurant Management System

## About the Project
This project is developed as part of the CodeAlpha Backend Development Internship (Task 3). It is a restaurant management backend built using Node.js, Express.js, and MongoDB.

## Technologies Used
- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript

## Features
- Menu management
- Order management and order status updates
- Inventory management and stock tracking
- Table management
- Reservation management
- Prevention of duplicate table reservations
- REST API endpoints for restaurant operations

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/sahanadm62-png/CodeAlpha_Restaurant_Management_System.git
   ```

2. Open the project folder:
   ```bash
   cd CodeAlpha_Restaurant_Management_System
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Configure your `.env` file with your MongoDB connection string and the port required by your application. Do not upload your `.env` file to GitHub.

5. Start the development server:
   ```bash
   npm run dev
   ```

## API Testing
The REST API endpoints can be tested using Thunder Client or Postman.
